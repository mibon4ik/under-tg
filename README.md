# Система автоматического Telegram-отчета продаж через Google Sheets

Профессиональный Node.js сервис для ежедневного автоматического расчета показателей продаж на основе Google Таблиц и их последующей отправки в Telegram получателям.

Архитектура проекта оптимизирована под работу **напрямую через Google Apps Script Web App**. Больше не требуется создавать сервисные аккаунты Google Cloud Console, скачивать `credentials.json` ключи и настраивать сложные права доступа API! Все данные запрашиваются через легкое веб-приложение сценария таблиц.

---

## 📋 Основные возможности
* **Без использования Google Cloud API**: Полностью исключает необходимость настройки Service Account, включения API в Google Console и управления сложными доступами.
* **Мульти-листовое чтение**: Автоматическое считывание данных одновременно с листов **Продления** и **Отмены** за соответствующий месяц.
* **Автоматическое определение листов по дате**: 
  - Май: `Общие продажи Май (Продления)` и `Общие продажи Май (Отмены)`
  - Июнь: `Общие продажи Июнь (Продления)` и `Общие продажи Июнь (Отмены)`
* **Интеллектуальная фильтрация**: Выборка записей строго за целевую дату, исключая строки с нулевым/отрицательным валом.
* **Разделение логики по листам**: 
  - Все строки из листа **Продления** распределяются по категориям активных продаж (`УЛИЦА`, `Продления МВМ`, `Продления Повторка`, `Сарафанка`, `Форсировка`) на основе колонки «ОТКУДА ЛИД».
  - Все строки из листа **Отмены** автоматически зачисляются в категорию **Отмены** независимо от исходного источника лида.
* **Пропуск пустых категорий**: Если за день по категории не было сделок, она скрывается.
* **Рассылка нескольким получателям**: Поддержка отправки отчета списку Chat ID (через запятую).
* **Railway ready**: Встроенный Express-сервер с healthcheck-эндпоинтами и механизмами автозапуска.

## 🛠️ Шаг 1: Развертывание Google Apps Script (Получение API URL)

1. Откройте вашу Google Таблицу.
2. Перейдите в верхнее меню: **Расширения** -> **Apps Script** (Extensions -> Apps Script).
3. Удалите весь стандартный код в редакторе.
4. Скопируйте содержимое файла [Code.gs](file:///c:/Users/User/Desktop/тг%20бот/GoogleAppsScript/Code.gs) и вставьте его в редактор.
5. Нажмите кнопку **Сохранить** (иконка дискеты).
6. В верхнем правом углу нажмите синюю кнопку **Начать развертывание** -> **Новое развертывание** (Deploy -> New Deployment).
7. Выберите тип развертывания: **Веб-приложение** (Web App, иконка шестеренки).
8. Задайте параметры:
   - Описание: `under-tg-sales-api`
   - Запуск от имени: **Вы** (Me, ваш аккаунт)
   - Кто имеет доступ: **Все** (Anyone) — *это критически важно для доступа с Railway бэкенда!*
9. Нажмите **Развернуть** (Deploy).
10. Предоставьте права доступа (Authorize access), выберите ваш Google-аккаунт, нажмите **Advanced** -> **Go to ... (unsafe)** и подтвердите разрешения.
11. Скопируйте полученный **URL веб-приложения** (оканчивающийся на `/exec`).

## 🚀 Шаг 2: Настройка и запуск Node.js (Railway)

### 1. Локальная настройка `.env`
Создайте файл `.env` в корневой директории проекта и укажите скопированный URL:

```env
# Токен бота Telegram (получить у @BotFather)
BOT_TOKEN=7123456789:ABCdefGhIJKlmNoPQRStUvWxYz

# ID чатов или пользователей Telegram для отправки (можно указать несколько через запятую)
CHAT_ID=-1001234567890,987654321

# URL веб-приложения Google Apps Script (полученный на Шаге 1)
APPS_SCRIPT_URL=https://script.google.com/macros/s/AKfycbz..._fake_url.../exec

# Часовой пояс для запуска cron и логирования
TIMEZONE=Asia/Almaty

# Порт Express-сервера
PORT=3000
```

### 2. Запуск локально
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите проект:
   ```bash
   npm start
   ```

## ☁️ Шаг 3: Деплой на Railway

1. Создайте проект на [Railway.app](https://railway.app/).
2. Нажмите **New Project** -> **Deploy from GitHub repo** и выберите ваш репозиторий.
3. Перейдите во вкладку **Variables** (Переменные) вашего сервиса в Railway и добавьте переменные окружения:
   - `BOT_TOKEN`
   - `CHAT_ID`
   - `APPS_SCRIPT_URL`
   - `TIMEZONE` = `Asia/Almaty`
4. После сохранения переменных Railway автоматически соберет и запустит проект. Он будет работать 24/7 и присылать отчеты каждый день в **21:00 по времени Алматы**.
5. Во вкладке **Settings** вы можете нажать **Generate Domain** для создания публичной ссылки (например, `https://your-service.up.railway.app`).

### API Эндпоинты:
* `GET /` — вернет `Bot is running`.
* `GET /health` — вернет `{"status":"ok"}`.
* `POST /send-report` — вручную запускает генерацию и отправку отчета за текущий день.
* `POST /send-report` с JSON телом `{"date": "20.05.2026"}` — сформирует и отправит отчет за прошедший период (полезно для тестов).
