# Система автоматического Telegram-отчета продаж через Google Sheets

Профессиональный Node.js сервис для ежедневного автоматического расчета показателей продаж на основе Google Таблиц и их последующей отправки в Telegram-каналы/чаты определенным сотрудникам.

## 📋 Основные возможности
* **Мульти-листовое чтение**: Автоматическое считывание данных одновременно с нескольких листов (по умолчанию `ОП-1` и `ОП-2`).
* **Интеллектуальная фильтрация**: Выборка записей строго за текущие сутки, исключая строки с нулевым/отрицательным валом или незаполненной датой.
* **Категоризация по источнику лидов** (колонка `D - ОТКУДА ЛИД`):
  1. `УЛИЦА` (с дополнительным подсчетом зашедших и отправленных договоров ДВД)
  2. `Продления МВМ`
  3. `Продления Повторка`
  4. `Сарафанка`
  5. `Форсировка`
  6. `Отмены` (автоматически рассчитывается и отображается при наличии отмен)
* **Пропуск пустых категорий**: Если за день по категории не было ни одной продажи, она автоматически скрывается из отчета.
* **Точные вычисления**: Формула среднего чека с защитой от деления на ноль.
* **Премиум-форматирование**: Разделение тысяч пробелом и добавление знака тенге (`₸`) без дробной части.
* **Рассылка нескольким получателям**: Поддержка отправки отчета списку Chat ID (через запятую).
* **Railway ready**: Встроенный Express-сервер с healthcheck-эндпоинтами и механизмами автозапуска.

## 🚀 Быстрый старт

### 1. Локальная установка и запуск

1. Клонируйте репозиторий или перейдите в папку с проектом.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` в корневой директории на основе шаблона и заполните его своими ключами.

4. Запустите проект в режиме разработки:
   ```bash
   npm start
   ```

## 🛠️ Настройка интеграции Google Sheets API

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект или выберите существующий.
3. Включите **Google Sheets API**.
4. В разделе **Credentials** (Учетные данные) создайте **Service Account** (Сервисный аккаунт).
5. Создайте новый JSON-ключ для этого аккаунта. Скачайте его.
6. Откройте скачанный JSON-файл:
   * Значение `client_email` скопируйте в переменную `GOOGLE_CLIENT_EMAIL`.
   * Значение `private_key` скопируйте целиком (включая кавычки и переносы `\n`) в переменную `GOOGLE_PRIVATE_KEY`.
7. **ВАЖНО**: Откройте вашу Google Таблицу в браузере, нажмите кнопку **Поделиться** (Share) и предоставьте доступ на чтение (Viewer) для адреса электронной почты вашего сервисного аккаунта (`client_email`).

## 🕒 Настройка расписания (Cron)

Служба автоматизации использует планировщик `node-cron`. 
По умолчанию отчет генерируется ежедневно в **21:00 по времени города Астана (Asia/Almaty)**.

Конфигурация cron-выражения в коде (`src/services/scheduler.service.js`):
```javascript
'0 21 * * *' // Выполняется в 0 минут, 21 час, каждый день
```

Приложение автоматически корректирует время в соответствии с часовым поясом, указанным в переменной `TIMEZONE`.

## 🌐 API Эндпоинты

Приложение предоставляет веб-интерфейс для контроля работоспособности и ручной отправки:

### 1. Проверка работы сервера
* **Метод**: `GET`
* **Путь**: `/`
* **Ответ**: `Bot is running`

### 2. Healthcheck (мониторинг статуса)
* **Метод**: `GET`
* **Путь**: `/health`
* **Ответ (JSON)**:
  ```json
  {
    "status": "ok"
  }
  ```

### 3. Ручной запуск отправки отчета
Позволяет принудительно сгенерировать и отправить отчет в Telegram за любую дату (полезно для ретроспективного анализа или проверки).
* **Метод**: `POST`
* **Путь**: `/send-report`
* **Тело запроса (JSON, опционально)**:
  ```json
  {
    "date": "20.05.2026"
  }
  ```
  *Если параметр `date` не передан, отчет будет сформирован за текущие сутки.*
* **Ответ (JSON)**:
  ```json
  {
    "success": true,
    "message": "Sales report generated successfully for date: 20.05.2026.",
    "telegram": {
      "success": ["-1001234567890"],
      "failed": []
    },
    "reportPreview": "..."
  }
  ```

## ☁️ Деплой на Railway

1. Создайте аккаунт на [Railway.app](https://railway.app/).
2. Подключите ваш репозиторий GitHub.
3. Добавьте новый сервис из вашего репозитория.
4. В разделе **Variables** (Переменные) добавьте все ключи, описанные в разделе **Конфигурация `.env`**.
5. Нажмите кнопку **Deploy**. Railway автоматически распознает Node.js проект, выполнит сборку, запустит команду `npm start` и сделает приложение доступным по внешней ссылке.
6. Вы можете настроить аптайм-мониторинг, указав URL эндпоинта `/health`.
